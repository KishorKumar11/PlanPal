Use SVG icons instead of emojis in all UI components and pages.

**Why:** User explicitly stated this preference during brainstorming for PlanPal.

**How to apply:** Any time UI code would use an emoji (e.g. 🎉, 👑, 🎯), replace it with a Lucide icon or a custom inline SVG instead. This applies to all new and modified components.
